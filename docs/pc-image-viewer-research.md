## Behavior verified in Microsoft's documentation

- **Opening and navigation.** Windows opens an image association from File Explorer into a single-image viewer. Left and Right move through images in the collection. Microsoft describes the 2026 Viewer and Gallery as separate surfaces, so an image-open action should go straight to that image. [2026 Photos announcement](https://blogs.windows.com/windowsexperience/2026/10/15/meet-the-new-photos-app-on-windows-11/)
- **Fit and magnification.** Photos documents a draggable, continuous 10–800% magnification slider alongside the preset choices. Screenshots 1, 2, 8, and 10 show automatic fitting at up to actual size, with the available viewport measured after the filmstrip and Info panel take their space. 100% denotes one image pixel per display pixel. The fit behavior and the preset values are derived from the supplied screenshots. [Photos zoom and metadata announcement](https://blogs.windows.com/windows-insider/2024/06/20/viewer-and-import-enhancements-for-microsoft-photos-on-windows-11/)
- **Filmstrip.** Microsoft documents that Filmstrip defaults to off when opening a photo and toggles with `F` or the bottom-left icon. The strip shows other photos in the same folder as selectable thumbnails beneath the current picture, with horizontal scrolling. [Filmstrip announcement](https://blogs.windows.com/windows-insider/2023/11/17/windows-photos-gets-background-remove-and-replace-along-with-other-improvements/)
- **Slideshow.** The playback button starts a slideshow from a photo or selected photos. Microsoft Photos adds transitions and optional soundtracks. The screenshot shows the launch affordance and does not show any playback controls. [Slideshow announcement](https://blogs.windows.com/windows-insider/2023/05/03/photos-app-for-windows-11-update-brings-improvements-for-windows-insiders/)
- **Metadata and location.** The bottom strip exposes dimensions and byte size. Info adds filename and date, and may show camera and location data if available. The screenshot also shows bit depth and DPI. Copy path should return the virtual file path, and Open location should reveal the containing folder in Files. Metadata that is unavailable should be omitted or labeled. [Photos zoom and metadata announcement](https://blogs.windows.com/windows-insider/2024/06/20/viewer-and-import-enhancements-for-microsoft-photos-on-windows-11/) · [2026 Photos announcement](https://blogs.windows.com/windowsexperience/2026/10/15/meet-the-new-photos-app-on-windows-11/)
- **Editing, rotation, and saving.** Edit (`Ctrl+E`) opens a dedicated editing experience with crop, rotate, flip, light/color adjustments, filters, markup, and reset. The viewer's rotation shortcut is visibly separate from Edit. The provided More menu distinguishes saving a copy from copying to the clipboard and from resizing image pixels. Zoom changes display magnification only. [Microsoft Photos editing guide](https://support.microsoft.com/en-us/windows/apps/photos/edit-photos-and-videos-in-windows)
- **Delete, share, and print.** Photos exposes these actions near the image. Deletion affects the underlying file, and the regular Windows flow uses the Recycle Bin. Sharing delegates to available OS apps. Printing and setting desktop/lock screen images are OS integrations. An in-game equivalent should act through the virtual drive, the in-game desktop and lock screen, and available app integrations. [Managing photos and videos](https://support.microsoft.com/en-us/windows/apps/photos/manage-photos-and-videos-with-microsoft-photos-app) · [Photos actions](https://support.microsoft.com/en-us/onedrive/windows/browse-your-photos-on-windows)
- **Open with.** Microsoft groups Explorer, Gallery, and platform-app routes so that related workflows are available without switching to Gallery first. Image 7 is the evidence for the exact grouping and visible entries. The mod can surface Files and implemented in-game apps. [Photos viewer enhancements](https://blogs.windows.com/windows-insider/2024/06/20/viewer-and-import-enhancements-for-microsoft-photos-on-windows-11/)
- **Scan Text and Visual Search.** The scanning icon beside Info is Scan Text, an OCR feature that recognizes text in the image for selection and copying. Visual Search takes an image as the query for a web search. These are distinct integrations. [Photos OCR announcement](https://blogs.windows.com/windows-insider/2025/03/24/march-2025-microsoft-photos-update-now-rolling-out-to-windows-insiders/) · [Bing Visual Search support](https://support.microsoft.com/en-us/bing/using-bing-visual-search)

## Implications for the in-game PC

An original UBS image viewer can use the same workflows with its own toolbar, palette, and layout. Images should be decoded from virtual-drive bytes with dimension and memory bounds. Opening through Files or the desktop should route supported image types into the viewer. Thumbnail navigation should stay within the current virtual folder, and the title and metadata should update with the selection.

UBS implements PNG, JPEG, BMP, GIF, and TIFF viewing using the Java image reader, with the first frame for GIF and the first page for TIFF. The viewer works with the virtual drive and its clipboard. Image edits save as a new PNG, and both background actions change the in-game PC. Windows printing, external sharing, OCR, Visual Search, Feedback Hub, and Clipchamp remain platform integrations.

Use one zoom model for the slider, wheel, buttons, presets, and fit mode. A 100% pixel scale on a Minecraft GUI divides the image dimensions by the GUI scale before drawing. Respect the viewport after changes to the filmstrip, inspector, and window size. Keep explicit zoom and automatic fit distinct. Image edits should be committed explicitly, with Save as writing a separate virtual-drive file.
