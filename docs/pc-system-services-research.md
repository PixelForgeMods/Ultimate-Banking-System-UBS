# Windows 11 references for in-game PC system services

Research covers Open, Save As, and Folder Picker (1), Virtual Drive and App Data (2), Default Apps and Open With (3), Shared Clipboard (4), and Desktop Search (6). Microsoft documentation establishes behavior. Screenshots show layout and are references for a distinct in-game design.

## Implementation groups

| Order | Components | Dependency |
| --- | --- | --- |
| 1 | **2. Virtual Drive and App Data**, then **1. Open, Save As, and Folder Picker** | The drive owns file identity, lookup, browsing, and safe mutations. Dialogs return references and save destinations that apps can use through this API. |
| 2 | **3. Default Apps and Open With**, and **4. Shared Clipboard** | Associations activate apps with drive references. Clipboard uses the same references for cut and copy, and the same write operations for pasting an image into a folder. These components can be built independently after Group 1. |
| 3 | **6. Desktop Search** | Search gets file metadata from the drive, app availability from the catalog, and opening behavior from associations. Settings results need direct routes to the real pages. Clipboard is independent of Search. |

Existing foundations include stable UUID entries in `PcFileSystem`, path resolution, case-insensitive file-name handling, a desktop search flyout that filters apps, file activation in `PcDesktopScreen`, and a file clipboard inside `PcFilesContent`. The PC API already has app registration and app lifecycle hooks. Extend these entry points and keep existing world data readable.

## Group 1. Drive, app data, and pickers

### Virtual Drive and App Data

- Windows gives standard user locations known-folder IDs and supports redirecting the underlying location. Explorer displays destinations such as Desktop, Documents, Downloads, and Pictures through navigation and Quick access. The in-game equivalent is a stable file or folder handle whose display path is resolved as needed. Renaming a file or moving it between folders should preserve the identity used by open documents, clipboard, and search. [Microsoft Known Folders](https://learn.microsoft.com/en-us/windows/win32/shell/known-folders) · [Microsoft File Explorer guidance](https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows)
- Windows app data is scoped to the user and app. It separates saved preferences and app files from caches and user-facing documents. Local data can survive an app update. Microsoft describes packaged Windows app data as removable with uninstall, which is distinct from user-owned documents and the PC's existing Marketplace lifecycle. Windows 11 no longer supports roaming app data through this API. [Microsoft app-data guide](https://learn.microsoft.com/en-us/windows/apps/design/app-settings/store-and-retrieve-app-data) · [Microsoft file-access permissions](https://learn.microsoft.com/en-us/windows/apps/develop/files/file-access-permissions)
- In-game contract: enumerate and resolve visible folders, get entry metadata and read bytes or UTF-8 text, create a file or folder, and update a file with collision handling. Expose an app-scoped persistent area keyed from the registered app ID and the desktop profile. Handle invalid names, duplicates, removed or recycled entries, folders passed to file-only methods, and write failures. Keep app-private data outside document results and file pickers. Public services deal in virtual handles and bytes. [Microsoft CreateFileAsync and collision options](https://learn.microsoft.com/en-us/uwp/api/windows.storage.storagefolder.createfileasync)
- App data has no dedicated end-user shell in this scope. A Windows Explorer reference shows it as hidden data within the user profile. The PC can give apps a dedicated storage API without populating the user's navigation tree with internal folders. [AppData Explorer visual reference](https://learn.microsoft.com/en-us/answers/questions/5403637/my-outlook-email-account-is-linked-to-one-drive-ho)

### Open, Save As, and Folder Picker

- **Shared layout.** Microsoft's Open and Save examples both show a title bar, Back/Forward/Up navigation, an address field, a location-search field, a left-hand places pane, and a middle file view. The bottom groups the name and type controls with a primary action and Cancel. Save includes New folder and a suggested filename. Microsoft's Folder Picker uses the same shell navigation and a folder-only selection mode. [Open and Folder Picker guide](https://learn.microsoft.com/en-us/windows/apps/develop/files/using-file-folder-pickers) · [Open screenshot](https://learn.microsoft.com/en-us/windows/apps/develop/files/images/picker-open-file.png) · [Save screenshot](https://learn.microsoft.com/en-us/windows/apps/develop/files/images/picker-save-file.png) · [Folder-picker visual reference](https://blockdyor.com/content/images/2023/10/How-To-Get-Started-On-BasicSwap-Step-12.jpg)
- **Open.** The app starts the dialog with a folder and accepted formats. The user navigates anywhere within the available drive, can filter files while preserving folder navigation, and chooses one or more existing items depending on the app's request. A folder activation navigates into it. The app receives confirmed file results. Cancel, Escape, and closing the dialog should return to the caller without changing its document. Windows supports both a single result and multiple results. [Microsoft App SDK picker walkthrough](https://learn.microsoft.com/en-us/windows/apps/develop/files/using-file-folder-pickers) · [Microsoft Common Item Dialog contract](https://learn.microsoft.com/en-us/windows/win32/shell/common-file-dialog)
- **Save As.** The app supplies an initial folder, suggested name, and output formats. The user can select or create a destination folder, type a name, and select a format. Apply a default extension when the name omits one and the selected format supplies one. Existing destinations prompt for explicit replacement. A declined replacement or invalid name should leave the dialog open. Cancel leaves the original and destination untouched. Keep file-format encoding in the app and return the destination only after confirmation. [Microsoft save-picker walkthrough](https://learn.microsoft.com/en-us/windows/apps/develop/files/pickers-save-file) · [Win32 options including overwrite](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/ne-shobjidl_core-_fileopendialogoptions)
- **Folder selection.** In folder mode, navigation and confirmation are different actions. Enter or double-click can browse into a highlighted folder. The explicit **Select folder** action returns the selected location, including the current location when the mode permits it, without treating a file as a destination. [Microsoft FolderPicker guidance](https://learn.microsoft.com/en-us/windows/apps/develop/files/using-file-folder-pickers)
- **In-game scope.** Reuse the virtual drive, folder names, file icons, and app chrome. Keep dialogs modal to the caller and restore its focus on completion. Show recoverable errors inline. Notes and Photos are end-to-end callers for Open and Save As. Folder choice should also be callable by third-party apps through the public API. [Microsoft common dialogs guidelines](https://learn.microsoft.com/en-us/windows/win32/uxguide/win-common-dlg)

## Group 2. File activation and clipboard

### Default Apps and Open With

- Apps identify extensions they can open and receive an activation carrying the selected files. A registration makes the app eligible. The user's choice determines the default. Windows can supply multiple files on activation, so the receiving app needs the document references and a defined way to handle repeated activations. [Microsoft file-activation contract](https://learn.microsoft.com/en-us/windows/apps/develop/launch/handle-file-activation) · [Microsoft application registration](https://learn.microsoft.com/en-us/windows/win32/shell/app-registration)
- The Windows 11 **Open with** redesign uses a compact themed app picker with an extension-specific title and icon-led options. **Just once** activates the selected app for this file. **Always** also saves it as the handler for the extension. Right-clicking a file offers an explicit alternative to normal opening. An unknown type offers a choice when a compatible installed app is available and should give a clear message when none is available. [Microsoft redesign announcement](https://blogs.windows.com/windows-insider/2022/03/02/announcing-windows-11-insider-preview-build-22567/) · [Screenshot of app list and footer buttons](https://www.ghacks.net/wp-content/uploads/2022/03/Windows-11-Build-22567-brings-a-new-open-with-dialog-style.jpg)
- **Settings > Apps > Default apps** lets the user look up an extension or select an app and view the types it handles. In-game preferences should be per PC profile, route through one association resolver shared by Files and Search, accept only installed compatible apps, and handle an uninstall or registration change without a dead link. Notes and Photos can preserve their current default behaviors while registered third-party handlers become selectable. [Microsoft Settings flow](https://support.microsoft.com/en-us/windows/apps/change-default-apps-in-windows) · [Default apps settings screenshot](https://learn.microsoft.com/en-us/answers/questions/3829662/context-menu-how-to-set-my-own-edit-app-for-images)

### Shared Clipboard

- The receiving app queries the available data format and chooses what it can paste. Windows defines distinct text, bitmap, and storage-item formats. Ordinary Ctrl+C and Ctrl+X produce content for Ctrl+V. A file cut records a move intent, and the move is completed when a destination accepts the paste. This differs from cutting selected text out of an editor immediately. [Microsoft copy/paste guide](https://learn.microsoft.com/en-us/windows/apps/develop/communication/copy-and-paste) · [Microsoft Shell clipboard formats](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard) · [Microsoft StandardDataFormats](https://learn.microsoft.com/en-us/uwp/api/windows.applicationmodel.datatransfer.standarddataformats)
- In-game text and image content can be copied as snapshots. File copy/cut carries live virtual item IDs and applies the actual transfer at paste time. Missing targets or transfer failures must preserve the source file. Clear a cut reference after a successful move. Files can materialize a copied image in the current folder. Notes can paste text. Photos and screenshot capture can publish image content so another app may consume it. [Microsoft Shell data transfer](https://learn.microsoft.com/en-us/windows/win32/shell/datascenarios) · [Microsoft Windows 11 Snipping Tool behavior](https://blogs.windows.com/windows-insider/2021/08/12/first-set-of-windows-app-updates-rolling-out-to-windows-insiders-for-windows-11/)
- Windows offers clipboard history as a separate optional surface opened through Win+V. The screenshot shows stacked image and text previews with per-item actions. Microsoft documents a 25-item history, a 4 MB history item limit, pinning, deleting, and clearing. Those are properties of history, not the live clipboard contract. The requested shared service needs the live typed clipboard. Cloud synchronization is a separate online feature. [Microsoft clipboard history settings](https://support.microsoft.com/en-us/windows/apps/using-the-clipboard) · [Windows 11 history screenshot and guide](https://www.microsoft.com/en-us/windows/learning-center/how-to-use-clipboard-history-in-windows-11)

## Group 3. Desktop Search

- **Entry and interaction.** Windows Search is accessible from the taskbar, by Win+S, and by typing from Start. The Windows 11 desktop search box returns apps, files, and settings as the user types. Filter categories narrow the list. Keyboard arrows select a result and Enter opens it. Search from File Explorer begins at a chosen folder or Home, which differs from system-wide taskbar search. [Microsoft taskbar Search](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows) · [Search keyboard navigation](https://support.microsoft.com/en-us/accessibility/windows/navigate-and-explore-the-windows-taskbar) · [Finding files and apps](https://support.microsoft.com/en-gb/windows/experience/storage-filemanagement/find-your-files-and-apps-in-windows)
- **Visual layout.** The familiar Windows 11 result view has a query, categories such as Apps and Documents, a Best match result, and a detail area with actions such as Open and Open file location. Microsoft's 2026 preview illustrates a newer single-list variant with file details and inline previews. The two designs differ, so use the earlier layout's hierarchy and the preview's clear labels for result sources without implying that all Windows releases share one arrangement. [Microsoft Best match guidance](https://support.microsoft.com/en-us/office/foundations-experiences/find-what-you-need-with-microsoft-search) · [Earlier result layout screenshot](https://learn.microsoft.com/en-us/answers/questions/4350512/windows-11-search-onedrive) · [Microsoft newer preview screenshots](https://support.microsoft.com/en-us/windows/experience/do-more-with-windows-search)
- **Search sources and opening.** Windows indexes metadata such as names and locations, as well as the contents of supported text files. Classic indexing favors known user locations and Enhanced increases coverage. The local virtual-drive equivalent can read the current metadata without implementing a background Windows Search index. Rank exact, prefix, and other matches consistently, exclude deleted and private entries, and distinguish an app from a document or a Settings page. Open a result through the resolver, or reveal its containing folder. Settings hits should route to implemented pages, such as Default Apps or Notifications. [Microsoft Search indexing guidance](https://support.microsoft.com/en-us/windows/experience/performance-optimization/search-indexing-in-windows) · [Microsoft newer Search preview](https://blogs.windows.com/windows-insider/2026/10/07/from-searching-to-doing-building-a-faster-more-streamlined-windows-search/)

## End-to-end checks

1. Open one and multiple filtered items, cancel safely, choose a folder, save a suggested name, reject an overwrite, then confirm one. Reopen the result and confirm text or image integrity.
2. Store app state, reopen the PC, and check that the same app can retrieve it while another app and Search cannot obtain it through their respective services. Verify a moved or renamed user document keeps its identity.
3. Open a document with a one-time alternate, make that app the default, and verify normal open from both Files and Search. Exercise an unavailable handler and restore the built-in default.
4. Paste Notes text, paste a screenshot or Photos image as a file, copy a file, and cut a file to another folder. Exercise a stale source and a failed transfer.
5. Use taskbar Search for an app, file, folder, and setting. Select a result with the keyboard, activate it, and check filtered and empty results.
