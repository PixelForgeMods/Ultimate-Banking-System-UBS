# References for Clock, Archive Manager, and PC Terminal

## Clock

- Windows Clock separates timers, alarms, stopwatch, world clock, and Focus. The alarm and timer guide shows a notification with Snooze and Dismiss, describes editable presets, and says alarms and timers continue when the app is closed or the device is locked while awake. In-game scheduling belongs to the desktop session, where it can be ticked independently of the Clock window. A countdown uses a deadline, an alarm compares local dates and times, and a snooze schedules another deadline. [Microsoft alarms and timers](https://support.microsoft.com/en-us/windows/apps/how-to-use-alarms-and-timers-in-the-clock-app-in-windows)
- Stopwatch is an elapsed-time utility with Start, Pause, Reset, and a lap/split control. The support screenshot shows a large time readout with controls below it. A monotonic clock is appropriate for elapsed time so time-zone or wall-clock changes leave the measurement alone. [Microsoft stopwatch guide and screenshot](https://support.microsoft.com/en-us/windows/hardware/clock/how-to-use-the-stopwatch-in-the-clock-app-in-windows) · [Java System.nanoTime contract](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/System.html#nanoTime())
- World Clock shows the same instant in multiple cities. Windows presents a city list and optional time comparison. An in-game list can use named IANA time zones and calculate local time and date from the same instant, including when a city has moved into the previous or next day. Daylight saving offsets come from the zone ID. [Microsoft world clock guide and screenshot](https://support.microsoft.com/en-us/windows/hardware/clock/how-to-use-the-world-time-clock-in-the-clock-app-in-windows) · [Java ZonedDateTime documentation](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/time/ZonedDateTime.html)
- Focus can be started from the Clock app, Settings, or the calendar and notification area. Settings such as hiding badges or turning on Do Not Disturb apply to the same session. A manually enabled Do Not Disturb mode can remain on after the session ends. The new Clock view pairs a large Focus timer with progress and optional integrations. Reuse the current in-game Focus model and delivery rules across entry points. [Microsoft Focus guidance](https://support.microsoft.com/en-us/windows/experience/focus-stay-on-task-without-distractions-in-windows) · [Windows Insider Clock visuals](https://blogs.windows.com/windows-insider/2021/08/19/new-clock-app-for-windows-11-with-focus-sessions-rolling-out-to-windows-insiders/)

## Archive Manager

- WinRAR has a file-browser mode and an archive-browser mode. It opens an associated archive from Explorer or its own file list, displays content as rows, and supports selecting all or part of the archive before opening the extraction destination dialog. Archive creation starts from selected files and folders and leads to archive naming and options. [WinRAR FAQ](https://www.win-rar.com/faq0.html)
- The visual hierarchy is a command toolbar above a location strip and a details list, with a status line below. Common commands include **Add**, **Extract To**, **Test**, **View**, **Delete**, **Find**, and **Info**. The publisher's brochure shows archive creation and option dialogs. A third-party screenshot illustrates the toolbar, location field, list, and status line together. Use those placements and labels with the in-game PC's original icons, colors, and controls. [WinRAR toolbar theme specification](https://www.win-rar.com/themes-new.html) · [Publisher's WinRAR brochure](https://www.win-rar.com/fileadmin/downloads/WinRAR_Product_brochure3p.pdf) · [WinRAR browser visual reference](https://www.isunshare.com/images/reviews/5-file-compression-software-which-one-will-be-your-choice/winrar-interface.png)
- A virtual-drive archive app can use standard Java ZIP input/output for listing, reading, testing, creating, and changing archives. Validate the whole extraction plan before committing any changes, restrict entry paths to relative names valid on the virtual drive, bound inflated bytes and entry counts, and give a clear result for collisions. Treat opaque entries as file bytes so viewing or extracting them does not execute them. RAR is a separate format with different headers and compression. RAR, encrypted archives, and any other unsupported formats should be identified explicitly. [Java ZIP package](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/zip/package-summary.html) · [RARLAB RAR 5.0 specification](https://www.rarlab.com/technote.htm)

## PC Terminal and CC:Tweaked

- CraftOS resolves aliases before looking up programs. The documented aliases include `ls` and `dir` for `list`. Each shell tracks its working directory; relative paths resolve from that directory. CraftOS exposes completion and can register completion callbacks for a program. The in-game terminal can use these conventions with the virtual drive, alongside understandable help, keyboard history, quoted paths, and completion for commands and filenames. [CC:Tweaked shell API](https://tweaked.cc/module/shell.html) · [Shell completion](https://tweaked.cc/library/cc.shell.completion.html) · [CC:Tweaked filesystem](https://tweaked.cc/module/fs.html)
- CraftOS presents a text terminal, with a tab strip above it for multishell. The terminal API writes text, changes cursor position and colors, and scrolls the terminal. The in-game app can borrow the tab strip, scrollback and monospaced terminal style. Keep each tab's working directory and command history local to that tab. A command file for this PC can dispatch the same in-game commands as interactively typed lines. [CC:Tweaked term API](https://tweaked.cc/module/term.html) · [CC:Tweaked multishell API](https://tweaked.cc/module/multishell.html) · [Official CC:Tweaked overview and visuals](https://tweaked.cc/)
- CraftOS runs Lua and exposes its own world and peripheral APIs. User-owned Lua source can be moved by an explicit file handoff. CC:Tweaked documents drag-and-drop onto an already-open computer as a `file_transfer` event, carrying each file's name and bytes. An optional in-game user-initiated export or copy workflow can rely on this without granting terminal commands access to remote computers. A later Java integration can use an optional dependency and CC:Tweaked's published `dan200.computercraft.api` namespace. The project publishes Minecraft 1.21.1 releases and documents NeoForge support. The Minecraft 1.21.1 API source defines the mod ID as `computercraft`. Confirm the release's loader constraints before adding a direct dependency. [CC:Tweaked file transfer event](https://tweaked.cc/event/file_transfer.html) · [CC:Tweaked integration guidance](https://github.com/cc-tweaked/CC-Tweaked#using) · [CC:Tweaked releases](https://github.com/cc-tweaked/CC-Tweaked/releases) · [Minecraft 1.21.1 API source](https://github.com/cc-tweaked/CC-Tweaked/blob/v1.21.1-1.120.2/projects/common-api/src/main/java/dan200/computercraft/api/ComputerCraftAPI.java#L36)

## End-to-end checks

1. Start a timer and close Clock. Open its notification and verify the timer reports completion once. Verify an enabled alarm can be snoozed, Stopwatch records a lap, and Focus started from Clock updates the session in Notification Center.
2. Open ZIP from Files, browse into a folder, test archive contents, and extract to the chosen virtual folder. Round-trip a new archive of text and binary files. Verify invalid entry names, collisions and inflated-content limits leave the drive consistent.
3. Open PC Terminal, use help, change directory, complete a quoted filename, read it, and launch an associated app. Verify separate tabs retain their own directories. Run a bounded terminal script and cancel a long or invalid operation. Verify interoperability controls describe the actual installed support.
