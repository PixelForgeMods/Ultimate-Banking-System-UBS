# Windows 11 backdrop materials for the UBS PC

Windows Acrylic combines a blurred backdrop with color and luminosity blending and fine noise. Blur controls which background detail survives. Tint and luminosity control how strongly that blurred background contributes to the final color. A surface can look nearly opaque while using strong blur. Mica is an opaque, wallpaper-tinted material for longer-lived app surfaces. [Microsoft Acrylic design guidance](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic) · [Microsoft material guidance](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/materials)

Microsoft confirms that the Windows taskbar and Start menu are affected by Transparency effects, and documents a separate clear-background policy for Windows sign-in. Its public material guidance does not specify a Windows 11 shell recipe for each surface. The 15% default and 40% OLED taskbar transparency figures sometimes quoted online belong to Microsoft's Windows 10 OEM documentation. [Taskbar and Start transparency](https://support.microsoft.com/en-us/accessibility/windows/use-color-and-contrast-for-accessibility-in-microsoft-365) · [Windows sign-in policy](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-logon#disableacrylicbackgroundonlogon) · [Windows 10 OEM figures](https://learn.microsoft.com/en-us/windows-hardware/customize/desktop/customize-the-taskbar#set-transparency-for-the-taskbar)

For comparison, Microsoft's public WinUI dark Acrylic theme defines the Default brush with `#2C2C2C`, `TintOpacity=0.15`, `TintLuminosityOpacity=0.96`, and solid fallback `#2C2C2C`. The dark Base brush specifies `#202020`, `0.50`, `0.96`, and fallback `#1C1C1C`. The WinUI AcrylicBrush source sets its own Gaussian `BlurAmount` to `30.0` and noise opacity to `0.02`. These identify public WinUI implementation parameters. The shell can use its own parameters. WinUI tint opacity applies to the tint layer, and its luminosity opacity separately regulates how background color shows through. [WinUI theme resources](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/Materials/Acrylic/AcrylicBrush_themeresources.xaml) · [WinUI blur and noise constants](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/Materials/Acrylic/AcrylicBrush.h) · [Microsoft acrylic property definitions](https://learn.microsoft.com/en-us/windows/apps/develop/ui/in-app-acrylic)

## Dark-mode starting values for UBS

The following numbers are proposed values for Minecraft. **Tint α** is the dark tint's weight in a simple blend with the blurred scene. The backdrop weight is `1 − α`. **Blur σ** is Gaussian standard deviation in logical Minecraft GUI pixels, before conversion to framebuffer pixels. A shader using sample radius needs its own conversion. Solid/near-solid controls and inner fills are separate layers. [Microsoft Gaussian blur units and kernel radius](https://learn.microsoft.com/en-us/windows/win32/direct2d/gaussian-blur)

| Surface | Windows evidence or interpretation | UBS starting value |
| --- | --- | --- |
| Taskbar strip | Microsoft confirms its transparency effect. The reference shows faint broad color through the strip under sharp controls. [Microsoft transparency guidance](https://support.microsoft.com/en-us/accessibility/windows/use-color-and-contrast-for-accessibility-in-microsoft-365) | `#1B1D23` at **86% tint**, **σ 10**. Draw app icons, badges, clock and date sharp. |
| Taskbar Search pill | The reference shows a distinct tinted pill on the taskbar. Treat it as a control layer over the strip. | Near-solid `#30394F` at **92% fill**, **σ 0 additional**. Draw magnifier, label and illustration sharp. |
| Start menu panel | Microsoft confirms its transparency effect and discusses acrylic in its Windows 11 desktop design guidance. [Windows 11 desktop design](https://learn.microsoft.com/en-us/windows-hardware/customize/desktop/wallpaper-and-themes-windows-11) | `#202020` at **85% tint**, **σ 14**. Use a shared background across the pinned grid and footer. |
| Search panel, Recent and typed results | Acrylic-style panel inferred from the supplied references. Microsoft documents a newer Search experience rolling out separately, so compare against the pictured build. [Microsoft Windows Search](https://support.microsoft.com/en-us/windows/experience/do-more-with-windows-search) | `#202020` at **85% tint**, **σ 14**. For the search field and result detail pane, use `#282B33` at **92% fill**, **σ 0 additional**. Keep rows, app icons and action labels sharp. |
| Start power flyout and app Jump List | Microsoft recommends background Acrylic on transient flyouts and context menus. Jump Lists are taskbar context menus. The specific shell brush values are unverified. [Acrylic flyout guidance](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic) · [Microsoft taskbar extensions](https://learn.microsoft.com/en-us/windows/win32/shell/taskbar-extensions#jump-lists) | Power flyout `#25262B` at **93% tint**, **σ 10** from the underlying desktop sample. Jump List `#25262B` at **88% tint**, **σ 12**. Apply the extra power-flyout contrast with its fill, without blurring Start's icons or labels into it. |
| Thumbnail preview and Peek | The reference thumbnail has a dark frame around a sharp window image. Microsoft documents the live window thumbnail and full-size Peek as window previews. [DWM thumbnails](https://learn.microsoft.com/en-us/windows/win32/dwm/thumbnail-ovw) · [DWM Peek](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmseticoniclivepreviewbitmap) | Frame only `#25262B` at **93% tint**, **σ 8**. Render the miniature and full-size Peek sharply with **σ 0**. |
| Sign-in | Windows has a documented Acrylic sign-in backdrop that can be disabled with a policy. [Windows sign-in policy](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-logon#disableacrylicbackgroundonlogon) | Keep the existing **56.1%** `#071A4C` full-wallpaper overlay. The current blur follows Minecraft's menu background blurriness setting. A calibrated Gaussian port could start at **σ 20**. Keep avatar, fields, labels and buttons sharp. |
| App windows and their title bars | Windows app bodies can be solid. Mica variants tint long-lived app chrome with wallpaper color and remain opaque. [DWM backdrop types](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type) | **100% opaque**, **σ 0**. An optional Mica-like color accent can sample the wallpaper for the title bar without exposing the windows behind it. |

Optional fine noise belongs on the Acrylic panels only. Start at **1% noise overlay opacity** and keep it below **2%** at this size. Use the existing solid surface colors as the fallback when transparency or blur is unavailable. Avoid blurring completed UI layers. Render the sampled backdrop below the surface, then its tint, stroke, icons and text. [Microsoft Acrylic recipe and solid fallbacks](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)

To measure parity, capture PNGs on the target Windows 11 build with dark mode, Transparency effects enabled, and display scale recorded. Use a flat dark patch, a flat bright patch, and a sharp edge behind each surface. Compare color attenuation on the patches and edge spread on the edge. Recheck against the original wallpaper and overlapping windows at common Minecraft GUI scales. Screenshots of the current taskbar and menus provide visual targets, while the exact platform settings and underlying pixels remain unmeasured.
