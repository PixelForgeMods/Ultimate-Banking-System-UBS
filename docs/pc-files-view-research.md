# File Explorer views and Ctrl+wheel

The supplied Windows 11 screenshot shows eight layout presets in menu order. They are Extra large icons, Large icons, Medium icons, Small icons, List, Details, Tiles, and Content. Details pane, Preview pane, and Show appear after the layouts and control other parts of the window. [Microsoft's File Explorer accessibility guide](https://support.microsoft.com/en-us/accessibility/windows/use-a-screen-reader-to-explore-and-navigate-file-explorer-in-windows) describes the layout and navigation regions, and [Windows 11 Inside Out](https://www.microsoftpressstore.com/store/windows-11-inside-out-9780137691333?link=text) covers all eight presets in Chapter 9.

- The larger icon layouts arrange items across the pane in rows and scroll vertically. Small icons put the name beside the icon. List puts small icons and names into columns that fill from top to bottom and scrolls across columns. Details adds sortable properties such as date modified, type, and size. Tiles place a larger icon beside a name and supplementary text. Date grouping is unavailable in List. [Microsoft Win32 list-view guidance](https://learn.microsoft.com/en-us/windows/win32/uxguide/ctrl-list-views) · [Shell view modes](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/ne-shobjidl_core-folderviewmode)
- Content presents each item in a full-width row with additional properties. Explorer uses the item's type to choose relevant metadata and drops lower-priority details as the window narrows. [Shell Content view](https://learn.microsoft.com/en-us/windows/win32/shell/prophand-content-view)
- Windows preserves view choices by folder. Compact view reduces spacing in the navigation pane and in List and Details layouts. Windows also supports Ctrl+Shift+1–8 to choose the menu presets in order. [Windows 11 Inside Out, Chapter 9, “Layouts, previews, and other ways to arrange files”](https://www.scribd.com/document/781335634/Bott-E-Windows-11-Inside-Out-2023) · [File Explorer in Windows](https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows)
- Show includes toggles for the Navigation pane, Item check boxes, File name extensions, and Hidden items. Alt+P toggles Preview pane and Alt+Shift+P toggles Details pane. [File Explorer in Windows](https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows) · [Windows keyboard shortcuts](https://support.microsoft.com/en-gb/accessibility/windows/keyboard-shortcuts-in-windows)

Ctrl+wheel changes icon size and appearance. Chapter 9 documents 76 incremental icon sizes available after selecting an icon preset, with successive wheel steps growing or shrinking the icons. Microsoft's Shell API exposes view mode and icon size as separate values. The nominal Shell icon sizes at 96 DPI are 16, 32, and 48 pixels for small, medium, and large. The jumbo Shell asset is 256 physical pixels. These are reference sizes for the Windows Shell and do not prescribe Minecraft GUI units. [Windows keyboard shortcuts](https://support.microsoft.com/en-gb/accessibility/windows/keyboard-shortcuts-in-windows) · [Windows 11 Inside Out, Chapter 9](https://www.scribd.com/document/781335634/Bott-E-Windows-11-Inside-Out-2023) · [SetViewModeAndIconSize](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifolderview2-setviewmodeandiconsize) · [Shell icon sizes](https://learn.microsoft.com/en-us/windows/win32/menurc/about-icons)

The sources above do not specify the exact wheel transitions among the four non-icon layouts or the full sequence of intermediate pixel sizes on the current Windows 11 build. Treat those details as implementation choices unless confirmed against a running Explorer instance.

The mod follows the menu order for layout transitions and uses 76 incremental icon sizes in Minecraft GUI units. Wheel up moves toward larger icon views and wheel down moves toward Content. Both ends stop at their limits. Home and Storage keep their dedicated layouts.
