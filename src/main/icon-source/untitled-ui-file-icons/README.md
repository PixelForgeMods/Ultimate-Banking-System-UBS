# Untitled UI file icons

These SVGs use the Default style from [Untitled UI File Icons](https://www.untitledui.com/resources/file-icons). Light uses a white page fill, and `dark/` uses a charcoal fill. Both have transparent backgrounds. The folder icon comes from the existing PC artwork.

Minecraft uses transparent PNGs under `src/main/resources/assets/ultimatebankingsystem/textures/gui/pc/file_types/`. Each theme has 40 × 40 textures for small draws and 512 × 512 textures in its `high_res/` directory for larger draws. Both sizes are rendered from the SVG source artwork, which is outside the packaged resources. See the [publisher's license](https://www.untitledui.com/license) for terms on distributing the source artwork.
