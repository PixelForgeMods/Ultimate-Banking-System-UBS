# Shop and shelf tools

> Fill many empty display slots with one reviewed batch.

## Select a source

Run `/ubs admin shop shelves fill`. The wizard first asks whether to use a whole mod, selected catalog items or carried inventory items with custom data. Selecting a mod continues to the item list.

![Shelf fill mod-source selection](screenshot:ultimatebankingsystem:68?width=1640&height=1257)

## Choose items and filters

Search the catalog by item name or registry ID. You can add individual items, restrict results to inventory or open Filter. Filter supports mod and item-tag choices; a filter changes what appears in the picker, not the shop's existing stock.

![Shelf fill item catalog](screenshot:ultimatebankingsystem:69?width=1633&height=1257)

![Choosing a filter category](screenshot:ultimatebankingsystem:70?width=1117&height=477)

![Mod include and exclude filters](screenshot:ultimatebankingsystem:71?width=1122&height=935)

![Item-tag filters](screenshot:ultimatebankingsystem:72?width=1117&height=930)

## Select shelves and review

Select affected shelves in the world. `/ubs admin shop shelves done` completes that selection step. In the review screen, check the number of empty slots, edit or remove items and adjust prices before choosing **Fill empty slots**. Existing filled displays are left alone by this action.

![Shelf fill review with prices and empty-slot count](screenshot:ultimatebankingsystem:73?width=1640&height=1257)

If a shop appears incomplete afterward, check saved cashier and terminal links in the Business Manager PC and load those chunks before editing. The setup objectives identify remaining requirements.
