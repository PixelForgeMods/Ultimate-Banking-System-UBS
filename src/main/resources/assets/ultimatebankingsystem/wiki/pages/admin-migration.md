# Importing another economy

> Preview and migrate data with backups.

## Numismatics

`/ubs admin import numismatics` opens the migration flow. Choose current-world data or an imported source file, define conversion policy, run a preflight scan, review the report and only then convert.

A full-economy conversion can affect accounts and physical items. Back up the world and keep the old mod installed until the process finishes; remove it only after the wizard instructs you, then restart.

## Other imports

`/ubs admin import` also offers CSV, EssentialsX, CMI and iConomy path-based imports. These are server-side paths, not arbitrary files on every player's computer.

Never run migration on the only copy of a live world. Review the preflight totals and resolve warnings before committing.
