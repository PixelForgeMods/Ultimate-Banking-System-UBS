# Notes and cheques

> Issue account-backed payment documents.

## Write documents

`/account note write <amount>` creates a bank note item. `/account cheque write <player> <amount>` creates a cheque for a named player.

These are account-backed documents, not ordinary UBS cash denominations. Keep the items secure and use the relevant redemption interaction shown in game.

The bank teller's Cash & Instruments section is where you can inspect related services. The screenshot shows that menu, not the final redemption confirmation; check the item and amount in game before accepting.
