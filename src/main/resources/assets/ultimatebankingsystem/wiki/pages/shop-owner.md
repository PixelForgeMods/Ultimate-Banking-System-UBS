# Running a shop

> Set up a shop, supply its displays and manage access.

## Start with the Business Manager

Create a shop in the Business Manager PC and follow its setup objectives. Claim the sales area and stockroom, choose checkout, then link the cashier, terminal and displays required by your shop type. A missing setup objective usually means a region or link has not been saved yet.

If a linked block is in an unloaded chunk, load that area before changing the setup. Saved links can remain valid while the chunk is unloaded.

## Shelves and stock

Open Shelf Manager to move between shelves. Set the displayed item, save a price and provide stock where required. **Set From Inventory** copies an item you carry; **Take Stock** returns physical stock. Creative shelves show infinite stock, so restocking them has no effect.

![Shelf Manager with item, price and stock controls](screenshot:ultimatebankingsystem:42?width=2560&height=1440)

The shop PC's Inventory and Orders views help you follow restocking, accepted orders and deliveries. Check these after a display appears empty or an order remains pending.

## Hours, lighting and permissions

Hours & Lighting stores one authoritative schedule in the **server timezone**. The Time: Local toggle changes only the display; edits still affect the server schedule. Closed-hours courier access and stockroom lighting are separate controls.

![Shop hours shown in server time](screenshot:ultimatebankingsystem:43?width=2560&height=1440)

![Same schedule shown in local time](screenshot:ultimatebankingsystem:44?width=2560&height=1440)

Delegate duties through staff roles and permissions. Grant only the stock, checkout or finance access a helper needs.

## Stockroom claim

Claim mode marks two opposite corners of the stockroom. Review the outline and displayed dimensions, then Apply; the selection clears after a successful region is added. Save & Exit closes the workspace without losing an already saved claim.

Shop-linked fixed terminals are controlled through checkout setup; they cannot be reconfigured by shift-right-clicking the terminal itself. See [Payment terminals](wiki:terminals).
