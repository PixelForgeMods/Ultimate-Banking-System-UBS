# Operator quick start

> Server setup and important administration entry points.

## Before players join

Keep a backup of the world before changing banking data or importing an economy. Review the UBS common configuration for account, bank, shop, job and heist policy.

Use `/ubs admin` for available operator commands and `/wiki` for the same in-game guide players see. Commands are permission-gated; opening this page grants no operator access.

## World setup

Place ATMs and bank tellers where accounts should be accessible. For jobs, spawn a Job Market and matching buyer/dispatcher NPCs. For stores, use claims and linked cashier, stockroom and display blocks.
