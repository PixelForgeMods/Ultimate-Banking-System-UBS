# Welcome to UBS

> Banking, shops, jobs and security in one place.

## Your first account

Run `/account open` to create a Central Bank checking account. This command does not open accounts at player-run banks; use that bank's teller instead.

Run `/account info list` to see your accounts, then `/account primary set <accountId>` to choose the account used by default.

## Where to go next

Use an ATM for PIN-protected banking. Visit a Job Market NPC to apply for a job and earn money. Shops let you buy and sell with UBS accounts.

Search above or choose a topic on the left. `/wiki` and `/ubs wiki` reopen this guide at any time. New to cash? Start with [currency denominations](wiki:currency) and [money straps](wiki:money-stacks).
